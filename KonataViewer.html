Konata Viewer

Onikiri2-Konata pipeline trace visualiser · v1.0.0

About

Enhanced web-based viewer for Onikiri2-Konata pipeline trace files (.kanata). Interactive visualisation of instruction execution through processor pipeline stages with gradient rendering, zoom, pan, and search capabilities.

Features

  • Gradient Stages — Official Konata gradient stage rendering
  • Color Schemes — Auto / Unique / ThreadID / Custom modes
  • Interactive Navigation — Zoom, pan, and search with keyboard shortcuts
  • Optimized Rendering — Level-of-detail text rendering for performance

Keyboard Shortcuts

  • Ctrl+O — Open file
  • + / − — Zoom in / out
  • F — Fit to view
  • Ctrl+F — Find/Search
  • Ctrl+B — Add bookmark
  • Escape — Clear selection
  • ? — Show this help

Mouse Controls

  • Click — Clear selection
  • Drag — Pan view
  • Scroll — Pan vertically
  • Shift+Scroll — Pan horizontally
  • Ctrl+Scroll — Zoom in/out

File Format

Supports standard Onikiri2-Konata trace format with commands:

  • I — Instruction definition
  • L — Instruction label
  • S — Stage start
  • E — Stage end
  • R — Retire
  • W — Dependencies
